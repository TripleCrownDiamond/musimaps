# @musimaps/shared

Contrats et données métier utilisés par les deux clients Musimaps.

Ce package contient :

- les types `Artist`, `Track`, `ArtistEvent` et `WaitlistEntry` ;
- le catalogue d’artistes et de villes ;
- les fonctions de recherche communes.

Il ne contient volontairement aucun code React, Expo, navigateur ou Supabase afin de rester portable.
